# CyberShield Project Context & Tracker

## 🛡️ Project Overview
CyberShield is a dual-architecture, open-source EDR (Endpoint Detection and Response) platform. It provides a centralized cloud dashboard and a lightweight, native endpoint agent for Windows that collects real-time telemetry (CPU, RAM, Disk, Network) and detects threats.

### Core Architecture
- **Frontend / Dashboard**: Next.js 14 (App Router) + React + Tailwind CSS + Zustand (State Management).
- **Endpoint Agent**: Node.js script (`agent/index.js`) packaged into a standalone `.exe` using `pkg`. It communicates with the dashboard via REST/WebSockets (`/api/telemetry`).

## 🚀 Current Features & Capabilities
- **Telemetry Collection**: Live CPU, Memory, Disk, and Network I/O stats.
- **Threat Detection**: Active process scanning, PE header checks, memory payload heuristics.
- **Fleet Management**: Centralized dashboard to view multiple nodes.
- **Security Posture**: AI Copilot guidance, forensics, and role-based access control.
